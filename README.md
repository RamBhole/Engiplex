# 📖 About

EngiPlex is a responsive web platform developed to showcase a startup dedicated to engineering services, technical training, internships, and career opportunities. The website provides an intuitive interface for students, professionals, and organizations to explore services, submit enquiries, and connect with EngiPlex.

The project emphasizes clean UI design, responsive layouts, and a user-friendly experience using modern web technologies.

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/RamBhole/Engiplex.git
```

### Open the project

Move the project into your local web server (XAMPP/Laragon/WAMP) if using PHP.

Example:

```
htdocs/
    Engiplex/
```

Start Apache and open:

```
http://localhost/Engiplex
```
